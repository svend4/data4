# Техническая спецификация
## Система управления персональным бюджетом для людей с инвалидностью

### 1. Обзор проекта

**Название:** BudgetAssist - Система управления персональным бюджетом для людей с инвалидностью в Германии

**Цель:** Создание доступного и инклюзивного приложения для управления персональными финансами людей с инвалидностью, интегрированного с немецкими социальными службами.

**Целевая аудитория:**
- Люди с различными формами инвалидности
- Социальные работники (Sozialarbeiter)
- Социальные педагоги (Sozialpädagogen)
- Волонтеры сопровождающих служб
- Представители социального ведомства (Sozialamt)

### 2. Технические требования

#### 2.1 Функциональные требования

**Основные функции:**
1. Учет доходов и расходов
2. Планирование бюджета
3. Отслеживание социальных выплат
4. Интеграция с Sozialamt
5. Генерация отчетов для социальных служб
6. Управление документами
7. Напоминания и уведомления
8. Многопользовательский доступ с ролями

**Роли пользователей:**
- **Клиент** - человек с инвалидностью (основной пользователь)
- **Социальный работник** - помощь в управлении бюджетом
- **Социальный педагог** - образовательная поддержка
- **Волонтер** - сопровождение и помощь
- **Представитель Sozialamt** - просмотр отчетов (только чтение)

#### 2.2 Требования доступности (WCAG 2.1 Level AA)

1. **Визуальная доступность:**
   - Поддержка screen readers (NVDA, JAWS)
   - Высокая контрастность (минимум 4.5:1)
   - Масштабирование до 200% без потери функциональности
   - Настраиваемые цветовые схемы
   - Крупные интерактивные элементы (минимум 44x44px)

2. **Моторная доступность:**
   - Полная поддержка клавиатурной навигации
   - Отсутствие временных ограничений на действия
   - Простые жесты (без сложных свайпов)

3. **Когнитивная доступность:**
   - Простой и понятный интерфейс
   - Визуальные подсказки и иконки
   - Режим "Упрощенного просмотра"
   - Голосовой ввод и вывод

4. **Языковая доступность:**
   - Немецкий (основной)
   - Русский
   - Английский
   - Упрощенный язык (Leichte Sprache)

#### 2.3 Технический стек

**Frontend:**
- React 18+ с TypeScript
- Material-UI с расширенной поддержкой accessibility
- React Aria для доступных компонентов
- i18next для мультиязычности
- Redux Toolkit для управления состоянием

**Backend:**
- Node.js + Express
- PostgreSQL для основной БД
- Redis для кэширования

**Безопасность и соответствие:**
- GDPR compliance
- End-to-end шифрование для чувствительных данных
- OAuth 2.0 + JWT для аутентификации
- Audit logging для всех операций

**Инфраструктура:**
- Docker для контейнеризации
- GitHub Actions для CI/CD
- Automated accessibility testing

### 4. Модель данных

#### 4.1 Основные сущности

**User (Пользователь):**
- id, email, password_hash
- role (client, social_worker, pedagogue, volunteer, sozialamt)
- accessibility_preferences (JSON)
- language_preference
- created_at, updated_at

**Client (Клиент):**
- id, user_id
- first_name, last_name
- disability_type, support_level
- sozialamt_id, case_number
- assigned_workers (social_worker_ids)

**Transaction (Транзакция):**
- id, client_id
- type (income/expense)
- category, amount, currency
- date, description
- sozialamt_relevant (boolean)
- attachments (документы)

**Budget (Бюджет):**
- id, client_id
- period (monthly/quarterly)
- categories (JSON с лимитами)
- social_benefits_amount

**Report (Отчет):**
- id, client_id, generated_by
- period, type
- data (JSON)
- sozialamt_submitted, submission_date

### 5. Безопасность и GDPR

#### 5.1 Защита данных
- Шифрование персональных данных at rest
- TLS 1.3 для передачи данных
- Регулярное резервное копирование
- Право на удаление данных (GDPR Article 17)
- Право на портируемость данных (GDPR Article 20)

#### 5.2 Аудит
- Логирование всех операций с персональными данными
- Отслеживание доступа социальных работников
- Регулярные отчеты о доступе к данным
