# Дизайн-документ
## BudgetAssist - Система управления персональным бюджетом

### 1. Принципы дизайна

#### 1.1 Основные принципы

**Доступность прежде всего (Accessibility First)**
- Каждый элемент интерфейса должен быть доступен для людей с различными формами инвалидности
- Следование стандартам WCAG 2.1 Level AA (стремление к AAA)
- Тестирование с реальными пользователями с инвалидностью

**Простота и ясность (Simplicity & Clarity)**
- Минималистичный дизайн без лишних элементов
- Четкая визуальная иерархия
- Понятные и однозначные действия

**Инклюзивность (Inclusivity)**
- Поддержка различных способов взаимодействия
- Адаптация под индивидуальные потребности
- Уважение к разнообразию пользователей

**Безопасность и приватность (Security & Privacy)**
- Визуальная индикация безопасности
- Прозрачность в обработке данных
- Контроль пользователя над своими данными

### 2. Цветовая схема и типографика

#### 2.1 Цветовые палитры

**Основная палитра (высокий контраст):**
```
Основной цвет:     #0D47A1 (Темно-синий)
Вторичный цвет:    #2E7D32 (Зеленый)
Акцентный цвет:    #F57C00 (Оранжевый)
Фон:               #FFFFFF (Белый)
Текст:             #212121 (Почти черный)
Текст вторичный:   #616161 (Серый)
Ошибка:            #C62828 (Красный)
Успех:             #388E3C (Зеленый)
Предупреждение:    #F9A825 (Желтый)
```

**Темная тема (для слабовидящих):**
```
Фон:               #121212
Текст:             #FFFFFF
Карточки:          #1E1E1E
```

**Режим высокой контрастности:**
- Контраст 7:1 и выше
- Черно-белая схема
- Увеличенная толщина границ

#### 2.2 Типографика

**Основной шрифт:**
- Inter (отличная читаемость, поддержка кириллицы)
- Резервный: -apple-system, BlinkMacSystemFont, "Segoe UI"

**Размеры:**
- H1: 32px / 2rem (жирный 700)
- H2: 24px / 1.5rem (жирный 700)
- H3: 20px / 1.25rem (средний 600)
- Body: 16px / 1rem (нормальный 400)
- Small: 14px / 0.875rem

**Требования:**
- Минимальный размер текста: 16px
- Высота строки: 1.5 (для основного текста)
- Поддержка масштабирования до 200%

### 3. Компоненты интерфейса

#### 3.1 Навигация

**Главное меню:**
- Крупные кнопки (минимум 48x48px)
- Иконки + текст (не только иконки!)
- Четкое выделение активного раздела
- Клавиатурная навигация (Tab, Arrow keys)

**Разделы:**
1. 🏠 Главная / Dashboard
2. 💰 Транзакции
3. 📊 Бюджет
4. 📄 Документы
5. 📈 Отчеты
6. 👥 Помощь (для социальных работников)
7. ⚙️ Настройки

### 4. Режимы отображения

#### 4.1 Упрощенный режим (Simple Mode)

**Особенности:**
- Крупные элементы (увеличение на 25%)
- Только основные функции
- Пошаговые визарды для сложных операций
- Больше визуальных подсказок
- Упрощенный язык (Leichte Sprache)

#### 4.2 Режим для социальных работников

**Особенности:**
- Многооконный просмотр
- Быстрое переключение между клиентами
- Массовые операции
- Расширенная аналитика
- Инструменты для создания отчетов

### 5. Адаптивность

#### 5.1 Брейкпоинты

- Mobile: 320px - 767px
- Tablet: 768px - 1023px
- Desktop: 1024px+
- Large Desktop: 1440px+

#### 5.2 Мобильная версия

**Приоритеты:**
- Оптимизация для одной руки
- Нижняя навигация
- Упрощенные формы (одно поле за раз)
- Поддержка жестов (но с альтернативами!)

### 6. Анимации и переходы

**Принципы:**
- Опция отключения анимаций (для людей с вестибулярными нарушениями)
- Плавные, но быстрые переходы (200-300ms)
- Отсутствие параллакса и автоплея
- Уважение к prefers-reduced-motion

### 7. Голосовое управление и ассистенты

**Поддержка:**
- Голосовой ввод для всех полей
- Голосовые команды для навигации
- Text-to-speech для всего контента
- Интеграция с системными голосовыми помощниками
