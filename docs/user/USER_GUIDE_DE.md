# BudgetAssist - Benutzerhandbuch

## Willkommen bei BudgetAssist!

BudgetAssist ist ein barrierefreies System zur Verwaltung Ihres persönlichen Budgets. Diese Anwendung wurde speziell für Menschen mit Behinderung entwickelt und entspricht den höchsten Barrierefreiheitsstandards.

## Erste Schritte

### Anmeldung

1. Öffnen Sie BudgetAssist in Ihrem Browser
2. Geben Sie Ihre E-Mail-Adresse und Ihr Passwort ein
3. Klicken Sie auf "Anmelden"

**Tipp:** Sie können die Tab-Taste verwenden, um zwischen den Feldern zu navigieren.

### Ihr Dashboard

Nach der Anmeldung sehen Sie Ihr persönliches Dashboard:

- **Aktueller Saldo:** Zeigt Ihr verfügbares Geld
- **Budget-Übersicht:** Wie viel Sie diesen Monat bereits ausgegeben haben
- **Anstehende Zahlungen:** Wichtige Zahlungen, die bald fällig sind
- **Letzte Transaktionen:** Ihre neuesten Einnahmen und Ausgaben

## Hauptfunktionen

### Transaktion hinzufügen

So fügen Sie eine Einnahme oder Ausgabe hinzu:

1. Klicken Sie auf "Transaktion hinzufügen"
2. Wählen Sie den Typ: Einnahme oder Ausgabe
3. Geben Sie den Betrag ein
4. Wählen Sie eine Kategorie (z.B. "Lebensmittel", "Miete")
5. Wählen Sie das Datum
6. Optional: Fügen Sie eine Beschreibung hinzu
7. Optional: Laden Sie einen Beleg hoch (Foto oder PDF)
8. Klicken Sie auf "Speichern"

**Wichtig:** Wenn eine Transaktion für das Sozialamt relevant ist, aktivieren Sie das Kontrollkästchen "Für Sozialamt relevant".

### Kategorien

**Einnahmen:**
- Sozialamt Leistungen
- Rente
- Behindertenbeihilfe
- Arbeitseinkommen
- Sonstige Einnahmen

**Ausgaben:**
- Wohnung/Miete
- Lebensmittel
- Transport
- Gesundheit
- Nebenkosten
- Versicherung
- Kleidung
- Körperpflege
- Kommunikation
- Freizeit
- Sonstiges

### Dokumente hochladen

Sie können Belege und wichtige Dokumente hochladen:

1. Gehen Sie zu "Dokumente"
2. Klicken Sie auf "Dokument hochladen"
3. Wählen Sie die Datei aus
4. Geben Sie einen Namen ein
5. Wählen Sie den Dokumenttyp
6. Klicken Sie auf "Hochladen"

**Unterstützte Formate:** PDF, JPEG, PNG
**Maximale Größe:** 10 MB

## Barrierefreiheit-Einstellungen

BudgetAssist kann an Ihre persönlichen Bedürfnisse angepasst werden.

### Einstellungen öffnen

1. Klicken Sie auf Ihr Profilbild (oben rechts)
2. Wählen Sie "Einstellungen"
3. Klicken Sie auf "Barrierefreiheit"

### Verfügbare Optionen

#### Visuelle Anpassungen

**Hoher Kontrast**
- Aktivieren Sie diese Option für bessere Sichtbarkeit
- Schwarz-Weiß-Darstellung mit verstärkten Kontrasten

**Textgröße**
- Wählen Sie zwischen 100% und 200%
- Standard ist 100%

**Farbschema**
- Hell: Heller Hintergrund (Standard)
- Dunkel: Dunkler Hintergrund
- Hoher Kontrast: Schwarz auf Weiß

#### Motorische Anpassungen

**Vereinfachte Ansicht**
- Größere Schaltflächen
- Mehr Abstand zwischen Elementen
- Einfachere Navigation

**Tastaturnavigation**
- Verwenden Sie Tab zum Navigieren
- Enter zum Auswählen
- Pfeiltasten in Menüs

#### Kognitive Unterstützung

**Vereinfachter Modus**
- Nur wichtige Funktionen sichtbar
- Schrittweise Anleitungen
- Einfache Sprache

#### Screen Reader Unterstützung

BudgetAssist funktioniert mit:
- NVDA (empfohlen für Windows)
- JAWS
- VoiceOver (Mac/iOS)
- TalkBack (Android)

**Wichtige Tastenkombinationen für NVDA:**
- NVDA + Pfeil unten: Nächstes Element
- NVDA + Pfeil oben: Vorheriges Element
- NVDA + Leertaste: Aktivieren

## Budgetverwaltung

### Budget erstellen

1. Gehen Sie zu "Budget"
2. Klicken Sie auf "Neues Budget erstellen"
3. Wählen Sie den Zeitraum (Monat oder Quartal)
4. Geben Sie Ihr Gesamteinkommen ein
5. Legen Sie Limits für jede Kategorie fest
6. Klicken Sie auf "Speichern"

### Budget überwachen

Ihr Budget zeigt Ihnen:
- Wie viel Sie geplant haben
- Wie viel Sie tatsächlich ausgegeben haben
- Verbleibender Betrag
- Warnungen bei Überschreitung

**Tipp:** Grüne Balken = Im Budget
**Warnung:** Gelbe Balken = Fast aufgebraucht
**Achtung:** Rote Balken = Überschritten

## Berichte für Sozialamt

### Bericht erstellen

Ihr Sozialarbeiter kann Berichte für das Sozialamt erstellen:

1. Gehen Sie zu "Berichte"
2. Klicken Sie auf "Neuer Bericht"
3. Wählen Sie den Zeitraum
4. Der Bericht wird automatisch generiert
5. Überprüfen Sie die Daten
6. Klicken Sie auf "Für Sozialamt einreichen"

### Was enthält der Bericht?

- Alle Einnahmen (besonders Sozialleistungen)
- Alle relevanten Ausgaben
- Belege und Dokumente
- Zusammenfassung des Budgets

## Häufig gestellte Fragen

### Wie sicher sind meine Daten?

Ihre Daten sind durch mehrere Sicherheitsebenen geschützt:
- Verschlüsselte Speicherung
- GDPR-konform
- Zugriff nur für autorisierte Personen
- Regelmäßige Sicherheitskopien

### Wer kann meine Daten sehen?

- **Sie**: Vollständiger Zugriff
- **Ihr Sozialarbeiter**: Zugriff mit Ihrer Zustimmung
- **Sozialamt**: Nur eingereichte Berichte

### Kann ich meine Daten exportieren?

Ja! Sie können alle Ihre Daten exportieren:
1. Gehen Sie zu "Einstellungen"
2. Klicken Sie auf "Daten exportieren"
3. Wählen Sie das Format (PDF oder CSV)
4. Klicken Sie auf "Exportieren"

### Kann ich meine Daten löschen?

Ja, Sie haben das Recht auf Löschung Ihrer Daten (GDPR Artikel 17):
1. Kontaktieren Sie Ihren Sozialarbeiter
2. Oder schreiben Sie an: datenschutz@budgetassist.example

### Wie verwende ich BudgetAssist mit einem Screen Reader?

1. Starten Sie Ihren Screen Reader (z.B. NVDA)
2. Öffnen Sie BudgetAssist
3. Verwenden Sie die Navigationslinks am Anfang der Seite
4. Alle Elemente sind mit Labels versehen

**Tipp:** Drücken Sie die Tab-Taste, um "Skip Links" zu aktivieren und direkt zum Hauptinhalt zu springen.

## Tipps für die tägliche Nutzung

### Gute Gewohnheiten

1. **Regelmäßig eintragen:** Tragen Sie Ausgaben sofort ein
2. **Belege hochladen:** Fotografieren Sie Belege direkt
3. **Budget prüfen:** Schauen Sie wöchentlich Ihr Budget an
4. **Fragen stellen:** Bei Unsicherheit Sozialarbeiter fragen

### Häufige Fehler vermeiden

❌ **Nicht:** Ausgaben vergessen einzutragen
✅ **Besser:** Gleich nach dem Einkauf eintragen

❌ **Nicht:** Belege verlieren
✅ **Besser:** Sofort fotografieren und hochladen

❌ **Nicht:** Budget ignorieren
✅ **Besser:** Regelmäßig kontrollieren
